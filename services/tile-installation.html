Define the surface before selecting the scope

A floor, bathroom wall and shower each call for a different project review. Tell us where the tile will go, what covers the surface now and whether you want to keep the existing layout. Note any visible damage or movement instead of assuming a new tile layer will resolve it.

For a wet-area renovation, see shower remodeling. If the tile is part of a larger room update, start with bathroom remodeling.

Make tile layout and edges part of the conversation

Tile size, pattern, grout choice and exposed edges affect both the appearance and the scope. Include product details or reference photos and explain which features matter most. Transitions into adjoining floors, doorway heights and trim should be discussed along with the tile itself.

Existing hardwood next to tile may also need a planned transition. Review hardwood installation if both surfaces are changing.

Separate surface preparation from installation

An estimate should make clear whether removal, substrate review, repairs and preparation are included. Wet-area work also needs an explicitly defined approach to the assembly beneath the tile. Existing damage or concealed conditions may need further assessment before the final scope is agreed.

Do not rely on appearance alone to decide whether an existing surface is ready. Share what you know about the current layers and any previous repairs when requesting a review.

Request a tile estimate with useful details

Send your city, room dimensions or approximate area, floor or wall photos, desired tile and timeframe. Mention access, occupied rooms and any other renovation work taking place. If you have not selected tile, say so; the initial conversation can focus on what needs to be measured and decided.

Project questions

Can tile be installed over the current surface?

That depends on the existing assembly and the selected material. Describe the current surface and any known issues so preparation and removal can be reviewed; do not assume an overlay is suitable.

Is a shower tile project the same as a bathroom remodel?

A shower project can be a defined part of a bathroom renovation. Clarify whether the request is for tile work alone or also involves the shower layout, fixtures, enclosure or other room changes.
